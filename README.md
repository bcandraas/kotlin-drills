# Kotlin Fundamentals Drills

I kept feeling like I was forgetting everything I learned the day after, like starting from zero every time. So instead of watching more tutorials, I broke Kotlin fundamentals into small drills I can actually remember.

Each one goes: learn a little → explain it back in my own words → write a small code snippet from memory.

## Drills covered

**Part 1 — Basics**
- Null safety (`?`, `?.`, `?:`, `!!`)
- Data class vs sealed class
- Scope functions (`let`, `apply`, `run`, `also`, `with`)
- Lambdas & higher-order functions
- Collections (`map`, `filter`, `groupBy`)

**Part 2 — Coroutines & Flow**
- suspend & launch
- async/await & Dispatchers
- Flow basics (collect, cold vs hot)
- StateFlow & operators

This is the full list from my learning plan — not all of them have code in this repo yet.

## Structure

Each folder is one topic/drill. Inside, files are named after what they actually demonstrate, not just numbered — e.g. inside the sealed class folder you'll find a basic example and a more complex nested version, since I usually do a few variations of each drill instead of just one.
